# «لَقْطَة» — رادار التخفيضات الكبرى وغلطات التسعير

تطبيق ويب ذكي وشامل يراقب أسعار المتاجر الإلكترونية الكبرى لحظياً، ويكتشف الصفقات الاستثنائية وغلطات التسعير (مثل نزول الأسعار بنسبة 50% إلى 99%).

## المميزات الرئيسية
- **تحديث فوري ولحظي (Real-Time SSE):** رصد التخفيضات وإظهارها فوراً على الشاشة بدون أي تحديث يدوي.
- **إنذارات صوتية فورية:** تنبيهات سمعية عند اكتشاف غلطات التسعير الكبرى.
- **كشف وتمييز البائع بدقة:**
  - 🟢 **أمازون أو نون نفسه رسمياً:** إبراز ببرواز أخضر وشارة موثوقية عالية.
  - 🟡 **شحن المتجر (Express / FBA):** شارة الشحن السريع المعتمد.
  - 🔴 **بائع خارجي:** شارة تنبيه واضحة.
- **تصفية ذكية:** حسب السوق (مصر / الإمارات)، نسبة الخصم، ونوع البائع.
- **واجهة مستخدم عربية كاملة RTL:** سريعة، متجاوبة مع الموبايل والديسكتوب.

## التشغيل محلياً
```bash
npm install
npm run build:web
npm run dev
```

يعمل الخادم على المنفذ `7860` (أو `4000` محلياً).
